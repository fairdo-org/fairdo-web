# Specifications

Our [FDO architecture specification](https://github.com/fairdo-org/fdo-architecture-spec) is now developed on GitHub using modern, collaborative practices. With transparent version control, pull requests, and issue tracking, we ensure faster, more reliable updates and greater community involvement—making the process clearer, more efficient, and fully traceable.

### Older Documents

**Please note** that older references are no longer maintained and may contain outdated or inconsistent information. For the most accurate and up-to-date details, always refer to the current specification hosted on GitHub.

The following lsit includes all official documents on FDOs which the FDO Forum has released. All documents followed the official process as ligned out in the FDO Process Document. The first documents described the core requirement specifications of the FDOs, while the others explain some details to better understand FDOs:

* [FDO Requirement specifications](https://zenodo.org/records/7782262) – a comprehensive list of FDO specifications endorsed by the FDOF
* [Data FDO](https://drive.google.com/file/d/1ySd4HB89nXYopUe0HK0bzCdbf8Zx5_Jl/view?usp=sharing) – a short and easy to read primer of the specifications for FDOs that contain data
* [FDO Overview](https://doi.org/10.5281/zenodo.7824713) – an overview about the various documents on FDO
* [Implementation of Attributes, Types, Profiles and Registries](https://doi.org/10.5281/zenodo.7825572) – a comprehensive document describing details about types and registries.
