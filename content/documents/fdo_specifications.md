The following table includes all official documents on FDOs which the FDO Forum has released. All documents followed the official process as ligned out in the FDO Process Document. The first documents describe the core requirement specifications of the FDOs, while the others explain some details to better understand FDOs. The most Important documents are:

* FDO Requirement specifications – a comprehensive list of FDO specifications endorsed by the FDOF
* Data FDO – a short and easy to read primer of the specifications for FDOs that contain data
* FDO Overview – an overview about the various documents on FDO
* Implementation of Attributes, Types, Profiles and Registries – a comprehensive document describing details about types and registries.
